# LLM Detection

Early exploration for detecting whether an essay was written by a student or generated by a large language model (LLM).

## Background

This repository holds my first pass at the Kaggle competition [LLM - Detect AI Generated Text](https://www.kaggle.com/competitions/llm-detect-ai-generated-text). The work continued as a team project with Josh Burch in [AI-Buster](https://github.com/Garcia-Burch-NLP/AI-Buster), which has the more complete analysis.

## Data

From the Kaggle competition:

- `train_essays.csv`: 1,378 essays with an `id`, `prompt_id`, the essay `text`, and a `generated` label (0 = student, 1 = LLM).
- `train_prompts.csv`: the two essay prompts the students responded to.

The raw Kaggle files are not included. Download them from the competition page into `data/llm-detect-ai-generated-text/`.

## What's Here

| File | Purpose |
| --- | --- |
| `wrangle.ipynb` | Loads the essays and prompts and takes a first look at the text |
| `preprocessing.ipynb` | Adds features such as essay length |
| `nlp_functions.py` | Text cleaning, tokenizing, stopword removal, and stemming |
| `explore.ipynb` | Compares word frequencies between student and AI essays |
| `ai_essays.ipynb` | Started work on generating extra AI essays with the OpenAI API, since the training set has very few AI-written examples |
| `student_responses_stemmed`, `aib_responses_stemmed` | Stemmed word lists produced during preprocessing |

## Status

This was an exploratory starting point and is not a finished model. The main open issue was class imbalance: the training data has almost no AI-generated essays, which is why the follow-up project brought in an external dataset of AI-written essays.
